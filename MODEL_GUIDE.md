## 🔄 Switching Between Models

### **Strategy: Use Multiple Models**

**For Best Results:**
1. **First pass**: Use Gemini Flash or GPT-4o Mini (cheap, quick)
2. **If concerning**: Run through Claude 3.5 (logical analysis)
3. **If critical**: Final check with GPT-4o or GPT-4

**Example workflow:**
```
Idea: Dog subscription box
├─ Gemini Flash: Quick check ($0.10) = RISKY
├─ Claude 3.5: Deep dive ($0.55) = RISKY (confirms)
└─ GPT-4o: Final analysis ($0.75) = RISKY (kill shot: CAC > LTV)

Total cost: $1.40
Confidence: High (all 3 agree)
```
